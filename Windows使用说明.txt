听题 0.2.0（Windows 64 位便携版）

1. 下载 InterviewAssistant-Windows-x64-v0.2.0.exe，关闭旧版，再双击新版。
2. 在窗口左侧展开“模型设置 · 豆包 / OpenAI”，选择“豆包 · 火山方舟”。
3. API 密钥：填写你在火山方舟新创建的密钥。不要发送到聊天中。
4. 服务地址：https://ark.cn-beijing.volces.com/api/v3
5. 模型 ID：doubao-seed-2-0-lite-260428
   如果你使用其他模型，以方舟控制台调用示例中的 model 值为准。
6. 接口类型：Responses（与你的方舟调用示例一致）。
7. 点击“保存设置，立即生效”，然后点击“测试连接”。
8. 连接成功后，在问题框输入问题并生成回答。

不再需要手工创建 .env 文件。已有 .env 仍可作为初始配置使用；
界面保存的配置优先于 .env，保存在本机用户数据目录 model-settings.json 中。
密钥以本机配置文件形式保存，文件不加密，不要分享或上传。

豆包当前仅支持文字回答，火山语音转写尚未适配。
401：密钥无效或已撤销。
403：未开通模型或没有调用权限。
404：模型 ID 或服务地址错误。
429：额度、余额或请求频率限制。
如果你曾将密钥截图发给他人，请先撤销旧密钥并创建新密钥。

仅在参与者同意、面试规则允许的场景使用。
此版本尚未签名，尚未经 Windows 实机录音和真实豆包密钥验证。
