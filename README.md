# 听题 · 面试辅助

面向化工、材料和半导体岗位的桌面原型，也可通过浏览器使用。采集会议播放音频，提取问题，并根据真实背景生成简短回答建议。仅在获得参与者同意且面试规则允许时使用。

## 运行

需要 Node.js 22 或更高版本。

```sh
npm ci
```

启动桌面版：

```sh
npm run desktop
```

打开左侧「模型设置」，选择豆包，填写方舟 API 密钥、模型 ID 和服务地址，点击「保存设置，立即生效」，然后「测试连接」。不再需要手动创建 `.env` 文件。豆包默认使用 Responses 接口；OpenAI 默认使用 Chat Completions，可在界面选择。

也可运行 `npm start` 后在本机浏览器访问 `http://127.0.0.1:3000`。设置文件只保存在本机，密钥不会通过读取状态接口返回，但会在用户填写并保存时经本机回环请求传到本机服务。桌面版配置路径为 Electron userData 下的 `model-settings.json`；开发版为项目根目录 `.model-settings.json`。配置文件不加密，请勿共享或提交。保留 `.env` 的兼容读取，界面保存的设置优先。模型 API 会产生费用，问题与背景会发送到配置的服务。

豆包地址为 `https://ark.cn-beijing.volces.com/api/v3`，模型 ID 以控制台调用示例为准。当前豆包仅适配文字回答，尚未适配火山语音识别；不会将录音发送到豆包不兼容的 Whisper 接口。

Windows 打包：

```sh
npm run dist:win
```

打包结果位于 `dist/`。Windows 发布版会兼容读取 `%APPDATA%/听题/.env`，但推荐直接在软件窗口中保存设置。发布包未配置签名，正式分发前需要签名和 Windows 实机验证。

## 使用

1. 填写岗位、真实项目、材料体系、工艺和表征经验。
2. 网页模式：在 Chrome / Edge 中选择会议所在标签页，勾选分享音频。此模式更容易将会议音轨与其他系统声音隔离。
3. 桌面模式：选择共享窗口或屏幕。Windows 使用系统回环音频，可能包含其他软件声音；请关闭其他音源。共享窗口不保证只捕获该窗口的声音。macOS / Linux 系统音频能力取决于系统权限与 Electron 支持，未实机验证。
4. 面试官问完后点击「停止并处理最后一段」，立即提交转写和回答；每段最多 60 秒。可直接输入或修正问题后生成回答。
5. 检查建议后用自己的话表达。清空会删除页面中的当前内容，刷新页面也不会保存背景。

## 当前范围

- 这是按段采集、转写、生成回答的可运行原型，尚非连续流式识别。延迟取决于录音长度、网络及模型服务，无固定秒数保证。
- 不采集麦克风。若会议音轨本身包含候选人或多位参与者，尚不支持声纹识别或严格说话人分离；“提问过滤”也可能误判。
- 无模型密钥时可浏览界面、填入示例，但不会生成虚假的示范回答。
- 回答不编造个人经历；缺失事实以待补充内容呈现。技术原理及参数仍需人工核实。
- 服务只监听本机，不包含账户体系，不应直接暴露到公网。

## 验证

`npm test` 覆盖实际本机 HTTP 服务、输入校验、跨站调用拦截、问题/非问题返回处理、音频转写请求、Responses 返回解析、设置保存与重启持久化、密钥不被状态接口返回，以及豆包录音转写不支持时的明确提示。测试用模拟模型服务验证集成，不代表真实模型效果或音频识别准确率。真实 API、会议采集与 Windows 安装包需要在目标电脑进一步验证。
