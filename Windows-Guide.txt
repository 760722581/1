听题 0.3.0（Windows 64 位便携版）

一、文字回答
1. 关闭旧版，双击 InterviewAssistant-Windows-x64-v0.3.0.exe。
2. 左侧“模型设置”中保留原有豆包设置，或选择“豆包 · 火山方舟”。
3. 填写方舟 API 密钥，保存设置并测试连接。
   默认服务地址：https://ark.cn-beijing.volces.com/api/v3
   默认模型：doubao-seed-2-0-lite-260428；请以你开通的模型 ID 为准。

二、语音识别（与文字模型分别开通、分别收费）
1. 在火山引擎控制台找到“语音技术”，开通“豆包录音文件识别模型”的极速版资源。
2. 创建或选择语音应用，获取该应用的 APP ID 和 Access Token。
3. 在听题左侧“语音识别设置”选择“火山引擎 · 录音文件识别极速版”。
4. 认证方式选择“APP ID + Access Token”，填入语音应用的对应值。
5. 资源 ID 以语音控制台为准。旧版国内极速资源常用 volc.bigasr.auc_turbo。
   如果控制台给出的是其他 ID，请填入控制台的值。
6. 如果你的语音服务只提供独立的 API Key，可选择“语音服务专用 API Key”认证方式。
   这不是方舟的文字模型密钥；不要将文字密钥填入语音认证栏。
7. 点击“保存语音设置”，立即生效。

三、测试与使用
1. 可以先上传一段有人说话的短录音测试；支持浏览器能解码的音频，最多 60 秒、15 MB。
2. 或点击“选择会议音频”，选择有会议声音的窗口或屏幕。
3. 面试官问完后点击“停止并处理最后一段”，软件自动转写并生成回答。
4. 录音会先在本机转换为 16 kHz 单声道 PCM WAV，再发送给火山语音接口；识别文字发送给豆包。
5. Windows 桌面版回环采集可能包括其他软件声音，请关闭音乐等其他音源。
6. 不请求麦克风权限。若会议音轨已混入候选人或其他参与者，本版不能可靠地分离面试官声纹。
7. 仍为分段识别，非连续流式；延迟取决于音频长度、网络和服务响应。

四、配置与隐私
配置保存到本机用户数据目录 model-settings.json，不用创建 .env。
旧版文字模型设置会保留。密钥以本机配置文件保存，未加密，不要分享文件或截图。
音频和问题会发送到你所配置的云服务，可能产生费用。
只在参与者同意、面试规则允许的场景使用。
